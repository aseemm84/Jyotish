A kundli (janma-kundali) is a birth chart: a map of the sky at the exact moment and place of birth, projected onto the twelve bhavas counted from the Lagna. This page explains how a chart is cast, then lets you compute a real one and follow each piece into the reference pages.

Kundli / Janma-kundali — birth chart — the positions of the nine grahas, the Lagna and the twelve bhavas at the birth instant, expressed in the sidereal (nirayana) zodiac.

What a kundli is

Vedic astrology reads the chart in the sidereal zodiac, measured from a fixed star point rather than the moving equinox. The difference between the two zodiacs at a given date is the ayanamsha; subtracting it from an ordinary (tropical) position gives the sidereal position Jyotisha uses. The chart is then a set of nine grahas seated in twelve rashis, read as twelve bhavas from the rising sign.

What you need

  • Date of birth — the calendar date.
  • Exact time of birth — to the minute if possible. This is the most important input: the Lagna moves about one degree every four minutes, and the finest divisions (D60) change every ~30 seconds.
  • Place of birth — resolved to latitude, longitude, and the UTC offset in force there at that date.
Handle with care. Everything on this page is a study aid for learning BPHS method, not a prediction or a judgement about any person. Because results hinge on birth time, treat a chart cast from an uncertain time as provisional — and take medical, legal, financial or personal decisions to a qualified professional, never to a chart.

How a chart is cast

  1. Fix the exact birth instant. Combine the date, the clock time, and the UTC offset that applied at that place and date. Errors here propagate into everything downstream.
  2. Compute sidereal positions. An ephemeris gives each graha’s longitude; subtract the ayanamsha (Lahiri by default) to place it in the sidereal zodiac. See Rashis and Dignity.
  3. Find the Lagna. From the instant and the coordinates, determine the sign and degree rising in the east — the anchor of the chart. See Lagna.
  4. Place the grahas. Seat each planet in its rashi and read its nakshatra and pada. See the 108 Padas tool and Grahas.
  5. Build the bhavas and vargas. Count the twelve houses from the Lagna (whole-sign by default), then derive the divisional charts — D9, D10 and the rest. See Bhavas and Vargas.
  6. Start the dasha clock. From the Moon’s nakshatra, compute the Vimshottari balance at birth and the sequence of periods. See Dashas.

Source BPHS, Vol. 1, Ch. 3–6 (sidereal positions, rashis, dignity, vargas) and Vol. 2, Ch. 46 (Vimshottari from the Moon’s nakshatra). The casting arithmetic itself is standard astronomy; BPHS supplies the framework the numbers are read within.

export default {
  async fetch(req) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "content-type"
    };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    if (req.method !== "POST")   return new Response("POST only", { status: 405, headers: cors });
    const upstream = await fetch("https://bharatephemeris.com/api/chart", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: await req.text()
    });
    const out = await upstream.text();
    return new Response(out, { status: upstream.status, headers: { ...cors, "content-type": "application/json" } });
  }

How to read what comes back
  • Lagna → its sign and lord set the whole chart — take it to Lagna.
  • Each graha’s dignity (exalted / own / friend / neutral / enemy / debilitated) → Dignity; remember the engine’s dignity is its own computation.
  • Each graha’s nakshatra · pada → click it to open the 108 Padas tool, now with rasi-first dignity.
  • Running period → the Vimshottari maha/antar in force — Dashas.
  • Vargas, ashtakavarga, yogas, arudhas, karakas, avasthas (in the raw response) → the matching pages on this site.

Accuracy, attribution & limits
The engine is an independent, in-house computation benchmarked against NASA/JPL Horizons and publishes its residuals openly — it is arc-minute class (Sun ~8″, Moon ~30″ at the 95th percentile), which its authors note is sufficient for Jyotisha (nakshatra-pada, cusps, muhurta) though not sub-arcsecond. It is a third-party service, so uptime and terms are outside this site’s control; please review their terms for anything beyond light personal study, and see their accuracy page for the method.
